# Калькулятор расчета навеса и забора из профильной трубы

Интерактивный 3D калькулятор для расчета стоимости и конструкции навесов и заборов из профильной трубы.

## Возможности

✅ **Настоящая 3D визуализация** на Three.js с поддержкой:
- Четырех типов навесов (арочный, двухскатный, односкатный, полуарочный)
- Забор с профнастилом и штакетником
- Интерактивное вращение, масштабирование, панорамирование
- Несколько предустановленных видов (сверху, спереди, сбоку, изометрия)

✅ **Автоматический расчет**:
- Площадь навеса и длина забора
- Стоимость конструкции (7000 ₽/м² для навеса, 1200 ₽/пог.м для забора)
- Доставка и монтажные работы

✅ **Полная спецификация**:
- Количество стоек, ферм, рядов обрешетки
- Расход кровельного материала
- Автоматический расчет в зависимости от параметров

✅ **Гибкие настройки**:
- Размеры (длина, ширина, высота)
- Типы материалов (профнастил, штакетник, сайдинг)
- Цвета (RAL палитра)
- Конфигурация конструкции (стандарт, усиленная, максимальная)
- Опции доставки и монтажа

## Использование

1. **Выбор режима**: переключайтесь между калькулятором навеса и забора
2. **Настройка параметров**: используйте ползунки и выпадающие списки слева
3. **3D просмотр**: 
   - **ЛКМ + перетаскивание** - вращение модели
   - **Колесо мыши** - приближение/отдаление
   - **Кнопки вида** - быстрое переключение между видами
4. **Расчет**: стоимость и спецификация обновляются в реальном времени

## Цены

- **Навес**: 7000 ₽/м²
- **Забор**: 1200 ₽/пог.м
- **Доставка**: рассчитывается автоматически
- **Монтаж**: рассчитывается автоматически

## Технические ограничения

- Шаг столбов: не более 2,5 м
- Шаг ферм: 1,5 м (стандарт), 1,25 м (усиленная), 1,0 м (максимальная)
- Шаг обрешетки: 40-50 см
- Профиль столбов: от 60×60×2 мм
